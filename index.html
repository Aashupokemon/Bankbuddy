What it is

A workspace built for the branch floor, not the head office.

Branch teams carry work in chat threads, registers and memory. BankBuddy gives that work one shared home: capture it in plain language, see it on a single board, and keep every change accountable — who did what, when, and why.

Capture in a sentence

Type it the way you’d say it. BankBuddy extracts the task, owner, due date and priority into an editable draft — nothing is saved until a person confirms.

Branch-scoped by default

Every read and write is resolved from your membership, never from anything the client sends. One branch can’t see or touch another’s board.

Accountable by design

Status changes need a reason, edits keep their before-and-after, and the audit trail is append-only, so a correction is a new entry — never an erased one.

Reminders that don’t spam

One nudge per task per occurrence, quiet hours respected, and a single overdue reminder each workday — not a notification storm.

How it works

Three steps, zero ceremony.

Say what needs doing

Free text, typed or pasted from the day’s thread. BankBuddy reads it as a draft, not as truth.

Check the draft

Owner, due date and priority come pre-filled and fully editable. Ambiguous dates get confirmed, never quietly guessed.

Work the board

Due, overdue, blocked and team views — with comments, reassignment and a history that shows what changed and why.

FAQ

Fair questions.

Is this connected to a real bank system?

No. BankBuddy is being built as an independent pilot on synthetic data only. It has no connection to core banking, customer records or KYC systems, and nothing here is bank-approved or a compliance opinion.

Does the AI create tasks on its own?

No. Extraction only produces a draft that a person edits and explicitly confirms. The model has no write access, and when extraction is unavailable the app falls back to a plain form.

Can one branch see another branch’s work?

Not by design, and it is enforced server-side and in the database, not hidden in the interface. Cross-branch access attempts are denial-tested as part of the build.

When can I try it?

There is no public sign-up. The pilot is scoped to a small set of branch users, and this page will change when there is something to open. The code and design notes are on GitHub in the meantime.
